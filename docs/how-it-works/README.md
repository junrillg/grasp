# grasp: how it works

This folder explains grasp itself: what it is for, what it can do and how the parts connect. The pages are plain Markdown with Mermaid diagrams, so they open in Obsidian and on GitHub. Read them in this order, widest first.

1. [App map](app-map.md): the whole skill on one page, its core features and how they connect.
2. [Architecture](architecture.md): how it is designed and why, what fails, and lessons on the system design ideas behind it.
3. [Features](features/README.md): one page per core feature, and a table of issues worked.
4. [Run records](runs/README.md): what agents did in this repository, task by task, newest first.
